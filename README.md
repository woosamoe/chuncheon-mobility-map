# 춘천 교통·보행 지도

춘천시의 실시간 도로 통행속도와 2021~2025년 공식 교통량 조사자료를 하나의 지도에서 확인하는 웹앱입니다.

- 차량 통행속도와 교통량은 서로 다른 지표입니다.
- 2025년 일별 관측 자료가 있는 지점에 한해 1주/1개월/분기/1년 평균을 표시합니다.
- 보행량은 아직 검증된 공식 자료를 확보하지 못해 빈 레이어로 둡니다.

GitHub Actions로 GitHub Pages에 배포합니다. 저장소의 `Settings > Pages > Source`를 `GitHub Actions`로 설정해야 합니다.
