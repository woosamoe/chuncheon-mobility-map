# 춘천 교통·보행 지도

춘천시의 실시간 도로 통행속도와 2021~2025년 공식 교통량 조사자료를 하나의 지도에서 확인하는 웹앱입니다.

- 차량 통행속도와 교통량은 서로 다른 지표입니다.
- 2025년 일별 관측 자료가 있는 지점에 한해 1주/1개월/분기/1년 평균을 표시합니다.
- 보행량은 아직 검증된 공식 자료를 확보하지 못해 빈 레이어로 둡니다.
- 제공된 가로등 현수기 노선도를 OpenStreetMap 도로망에 맞춘 벡터 선으로 표시하고, 11월 예약현황 엑셀의 ID·구간명·구간별 총 게첨 수량을 검색할 수 있습니다.
- 현수기 수량은 날짜별 잔여 수량이 아니라 구간 총량이며, 수량 미기재 구간은 확인 필요로 표시합니다.
- 춘천시의 2026년 2월 17일 기준 지정 벽보게시판 29곳을 관리번호·주소·위치 설명과 함께 검색하고 지도에서 확인할 수 있습니다.

GitHub Actions로 GitHub Pages에 배포합니다. 저장소의 `Settings > Pages > Source`를 `GitHub Actions`로 설정해야 합니다.

현재 배포 원본은 `chuncheon_webapp_deploy_source_v4.zip`이며, 기존 ZIP은 이전 버전 보관용입니다.
